# Project Notes

## Current status

This repository is the **baseline RGB/HSV prototype**.

## What is scientifically safe to claim

Safe:
- pixel-level image analysis
- explainable RGB/HSV rule-based classification
- approximate category distribution
- image-processing prototype

Do not claim yet:
- true multispectral classification
- NDVI/NDWI/NDBI from ordinary RGB
- geographic area in hectares
- high accuracy
- GIS-accurate land-cover mapping
- ML classification

## Suggested next development sequence

1. Run and debug the baseline.
2. Test with real satellite images.
3. Record observations and limitations.
4. Improve preprocessing and thresholds.
5. Add multispectral data support.
6. Add NDVI/NDWI/NDBI when valid bands are available.
7. Add georeferencing and physical area.
8. Add labeled validation and accuracy evaluation.
9. Consider ML classification.
